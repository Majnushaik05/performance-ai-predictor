# AI Stock Predictor

An intelligent stock market forecasting and trend prediction platform for Indian indices (**NIFTY 50**, **SENSEX**, and **BANKEX**).

## Features

- **Professional Clean Light Theme**: White background with high-contrast black typography and emerald green momentum accents.
- **AI Stock Trend Verdict**: Immediate high-probability Bullish (Buy Signal) vs. Bearish (Exit Signal) forecasts with confidence percentage.
- **Visual Trend Reversal Indicator**: Analyzes prior session returns against current intraday price action to identify mean-reversion surges and momentum exhaustion.
- **Floor Trader Pivot Levels**: Real-time calculation of Pivot Points ($PP$), Support ($S1, S2$), and Resistance ($R1, R2$).
- **Live Candlestick Anatomy**: Interactive SVG candle showing wick rejection, body size, and intraday range.
- **Broker Live Feed**: Optional AngelOne SmartAPI integration with Web Crypto RFC 6238 TOTP computation.
- **Onboarding Flow**: Landing overview, guest explorer, and session audit history.
